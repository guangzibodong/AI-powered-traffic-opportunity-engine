# TrafScope Commerce OS Product Spec

This repo follows the supplied v0.2 spec for building TrafScope as an AI traffic operator for WooCommerce and WordPress ecommerce stores.

## Product Promise

Connect your store and GSC. In 10 minutes, get a task board showing what to optimize, what pages to create, which products to push, and how to track the result.

## Core Loop

```txt
Store data -> Search signal -> Product mapping -> Traffic opportunity -> Auto task -> SEO/page/product action -> Draft/publish -> Search + AI + sales feedback
```

## MVP Scope

- WooCommerce + WordPress first.
- Google Search Console ingestion.
- Product-keyword-page graph.
- Deterministic TrafScore and ProductReadiness scoring.
- Opportunity rules for product SEO, collection pages, buying guides, CTR refreshes, and ranking pushes.
- Task board with evidence and action plans.
- Draft asset generation.
- WordPress draft publishing with human approval.
- Performance feedback after publication.

## Non-goals

- Full SEO database.
- Backlink database.
- Full AI visibility monitoring.
- TikTok, YouTube, Reddit, or Xiaohongshu scraping.
- Fully autonomous publishing.
- Shopify support before WooCommerce MVP works.
